DebbyKalori — calorie estimation from a food photo

Thesis project · Universitas Muhammadiyah Surabaya

A two-stage pipeline. First it classifies the food ingredient in a photo: YOLOv8 isolates each object, a frozen ViT-Base turns it into a 768-dimension embedding, and XGBoost assigns one of ten classes. Then the calorie figure is computed, not guessed — the weight the user enters is multiplied against the Indonesian food composition table (TKPI 2020).

  • Ten ingredient classes, each tied to a fixed kcal value per 100 g.
  • Evaluated with precision, recall, F1-score, and a 10×10 confusion matrix to see which classes the model confuses.
  • Wrapped in a Streamlit app so the model can be used without touching code.

Python · PyTorch · ViT-Base · XGBoost · YOLOv8 · Streamlit — source and full evaluation
